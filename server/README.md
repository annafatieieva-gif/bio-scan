# Сервер сповіщень — розгортання на Cloudflare (безкоштовно, без термінала)

Цей маленький сервер робить лише одне: раз на день перевіряє, чи не настав
час якогось аналізу, і якщо так — надсилає push-сповіщення на телефон,
навіть якщо додаток закритий. Сервер не бачить і не зберігає жодних
медичних даних — тільки назви аналізів з "Нагадувань", періодичність, дати
й технічну підписку на сповіщення.

Усе робиться через веб-панель Cloudflare, клацанням — термінал не потрібен.

## Крок 0 — важливо про iOS

Push-сповіщення в Safari на iPhone працюють **тільки для додатків, доданих
на головний екран** ("На головний екран" через кнопку "Поділитися"). Просто
у вкладці Safari вони не працюють. Тобто спершу онови сайт з новими
файлами, видали старий ярлик і додай додаток на головний екран заново.

## Крок 1 — акаунт Cloudflare

Зайди на [dash.cloudflare.com](https://dash.cloudflare.com) → зареєструйся
(безкоштовно, потрібен лише email).

## Крок 2 — створити Worker

1. У лівому меню: **Workers & Pages** → **Create**
2. **Create Worker** → дай назву, наприклад `my-bioscan-push` → **Deploy**
   (спершу створиться шаблонний "Hello World" — це нормально)
3. Натисни **Edit code** (або "Continue to project" → "Edit code")
4. Виділи весь код у редакторі (Cmd+A) і видали
5. Встав туди **весь вміст файлу `server/worker.js`** з цього архіву
6. **Save and deploy** (кнопка вгорі праворуч)

## Крок 3 — сховище для нагадувань (KV)

1. У лівому меню: **Workers & Pages** → **KV**
2. **Create a namespace** → назва `REMINDERS` → **Add**
3. Повернись у свій Worker → вкладка **Settings** → **Bindings** →
   **Add binding** → тип **KV Namespace**
4. Variable name: `REMINDERS` (рівно так, великими літерами)
   KV namespace: обери щойно створений `REMINDERS`
5. **Save**

## Крок 4 — ключі (Environment Variables)

Там же в **Settings → Variables and Secrets** → **Add variable** — додай
три змінні (тип можна лишити "Text", для приватного ключа краще "Secret"):

| Variable name | Value |
|---|---|
| `VAPID_PUBLIC_KEY` | `BNwlB4UxR7eKB4SwHNnI8ZWJccDdWtVyGxWoGaIlc6AFONbhXuiNXlr28Cetsz5LbM1COBn4ond5hr-BYirLzRE` |
| `VAPID_PRIVATE_KEY` | `S5y1Oy2k_2LFtTdAuJdhxJGkd0S5tIHyZAdMzWmdvlQ` |
| `VAPID_SUBJECT` | `mailto:твоя-пошта@приклад.com` (будь-яка твоя пошта, для контакту) |

**Збережи ці ключі кудись окремо** (нотатки, менеджер паролів) — якщо
колись розгортатимеш сервер наново, знадобляться ті самі.

**Save and deploy**.

## Крок 5 — щоденна перевірка (Cron Trigger)

**Settings → Triggers → Cron Triggers → Add Cron Trigger**

Впиши: `0 9 * * *` (це означає "щодня о 9:00 за Гринвічем" — приблизно
опівдні за київським часом; онови на свій смак, формат — звичайний cron).

**Add**.

## Крок 6 — підключити додаток

1. На головній сторінці Worker'а скопіюй адресу — щось на кшталт
   `https://my-bioscan-push.твій-нік.workers.dev`
2. Відкрий My BioScan на телефоні → вкладка **"Нагадування"** → картка
   **"🔔 Сповіщення"** → встав цю адресу в поле → **"Увімкнути сповіщення"**
3. Дозволь сповіщення, коли iOS запитає
4. Натисни **"Надіслати тестове"** — за кілька секунд має прийти пуш

## Діагностика

- Якщо тестове сповіщення не прийшло — переконайся, що додаток
  встановлений на головний екран (не просто вкладка Safari)
- `[адреса воркера]/run-check-now` у браузері — вручну запускає ту саму
  перевірку, що й щоденний cron; корисно, щоб перевірити логіку не чекаючи
  наступного дня
- Логи помилок: у Cloudflare — вкладка **Logs** у Worker'і (треба увімкнути
  "Begin log stream")
