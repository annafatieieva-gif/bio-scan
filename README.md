# My BioScan — особистий трекер здоров'я

Веб-додаток (PWA), який встановлюється на головний екран iPhone і працює офлайн.
**Усі дані зберігаються тільки локально на телефоні** (в IndexedDB браузера) —
нічого нікуди не відправляється.

## Що вміє
- 📷 Фото висновку лікаря → автоматичне розпізнавання тексту (OCR)
- 📄 Завантаження PDF з аналізами → витяг тексту (або OCR, якщо це скан)
- Автоматичний пошук ~20 типових показників (гемоглобін, глюкоза, холестерин,
  ТТГ, вітамін D тощо) зі списком для перевірки перед збереженням
- 📈 Графіки динаміки показника за весь час
- ⏰ Список аналізів для регулярного контролю з датою "востаннє" і статусом
  (прострочено / скоро / ОК) + експорт нагадування у файл `.ics` для Календаря iPhone

## Як встановити на iPhone (потрібен будь-який статичний хостинг)

Найпростіший безкоштовний варіант — **GitHub Pages**:

1. Створи новий репозиторій на github.com (можна приватний)
2. Заливаєш усі файли з цієї папки (`index.html`, `style.css`, `app.js`, `ocr.js`,
   `manifest.json`, `sw.js`, `icons/`)
3. Settings → Pages → Deploy from branch → `main` / `root`
4. Через хвилину-дві додаток буде за адресою на кшталт
   `https://твій-нік.github.io/назва-репо/`
5. Відкрий цю адресу в **Safari на iPhone**
6. Кнопка "Поділитися" → **"На головний екран"**
7. Готово — іконка з'явиться як звичайний додаток, повноекранно, без Safari

Альтернативи GitHub Pages: Netlify, Vercel, Cloudflare Pages — процес аналогічний
(перетягнути папку → отримати посилання).

## Важливі чесні застереження

- **OCR не ідеальний.** Розпізнавання рукописного тексту чи нечітких сканів буде
  давати помилки — тому перед збереженням завжди показується список знайдених
  значень для перевірки/виправлення.
- **Нагадування в iOS PWA обмежені.** Safari на iPhone не дозволяє надійно
  планувати "тихі" локальні сповіщення наперед без сервера пуш-нотифікацій.
  Тому реалізовано два надійні механізми замість цього:
  1. При відкритті додатку на "Головній" одразу видно, що прострочено/скоро.
  2. Кнопка "📅 .ics" створює файл, який відкривається Календарем iPhone і
     дає справжнє системне нагадування в потрібний день.
- **Референсні діапазони** ("норма") у додатку — загальні орієнтовні значення
  для дорослих, а не медична рекомендація; лабораторії часто мають свої
  референси, які пишуться поруч із результатом аналізу.
- Дані живуть в IndexedDB конкретного браузера на конкретному пристрої.
  Якщо очистиш дані Safari або поміняєш телефон — вони не переносяться
  автоматично. Якщо захочеш бекап/синхронізацію між пристроями — це наступний
  крок, який вимагає або iCloud-інтеграції, або власного бекенду.

## Самонавчання: нові показники додаються автоматично

Якщо в тексті знайдено рядок, схожий на показник ("Назва + число + одиниця"),
якого немає в базовому словнику, — він з'явиться в окремому блоці "Схожі на
показники — додатку ще невідомі" при збереженні запису. Достатньо перевірити
назву/одиницю і поставити ✓ — показник:
1. збережеться в цьому записі й одразу з'явиться на графіку динаміки;
2. запам'ятається (в IndexedDB, локально), і з наступного разу такий самий
   показник буде розпізнаватися автоматично, без підтвердження.

Це працює і для ручного вводу — вивчені показники теж з'являються у
випадаючому списку.

## Динаміка: окрема картка-графік на кожен показник

На вкладці "Динаміка" кожен обраний показник тепер отримує свою окрему
картку зі своїм графіком і своєю шкалою — бо показники мають різні одиниці
виміру (г/л, ммоль/л, ×10⁹/л...), і накладати їх на один спільний графік з
однією віссю було б оманливо. Обери кілька чіпів — картки з графіками
накопичуються одна під одною на тій самій сторінці.

Референтний діапазон показано як заштриховану горизонтальну смугу на фоні
графіка — це працює навіть тоді, коли для показника є лише ОДНА точка даних.

Кнопка "📌 Закріпити цей вибір" запам'ятовує поточний набір показників, і
вкладка відкриватиметься з ним же наступного разу.

## Референсні значення — читаються з самого бланка

Додаток тепер спершу намагається знайти референтний діапазон ("норма") прямо
поруч із результатом у тексті самого аналізу — адже різні лабораторії
використовують різні межі. Якщо в тексті такий діапазон знайдено (наприклад
"4.0 - 5.5" чи "< 4" одразу після результату й одиниці), використовується він.
Якщо ні — застосовується загальний орієнтовний діапазон із внутрішнього
довідника (`ref` у `TEST_DICTIONARY`).

**Обмеження, чесно:** для показників з багаторівневими віковими нормами
(наприклад феритин, де на бланку є окремі діапазони для новонароджених,
дітей, дорослих) розпізнавання може підхопити не той рівень — завжди звіряй
з оригінальним бланком у вкладці "Записи", якщо є сумніви. У вікні
підтвердження перед збереженням видно, який саме референс було розпізнано.

## Дизайн: ботанічні акценти

У додатку тепер є м'який рослинний мотив — стилізовані листя монстери
(з характерними прорізами) та епіпремнуму (пасифлори/потоса), намальовані
у власній кольоровій гамі додатку:
- `assets/corner-vine.svg` — звисаюча ліана з листям монстери й епіпремнуму,
  зафіксована у кутках екрана (11-16% прозорості, позаду карток)
- `assets/header-vine.svg` — акцент ліани в кутку шапки
- `assets/empty-illustration.svg` — повноцінна кольорова ілюстрація для
  порожніх екранів (Записи/Динаміка/Нагадування, поки там ще нічого немає)

Якщо захочеш змінити відтінок чи щільність — кольори та прозорість
заведені прямо в SVG-файлах (`fill-opacity`/`opacity`), можна редагувати
без перегенерації.

## Редагування записів

У деталях запису (вкладка "Записи" → тапнути на запис) тепер є кнопка
"✏️ Редагувати" — можна змінити назву, дату, значення будь-якого показника,
видалити зайвий показник (зняти ✓) або додати новий вручну прямо в цей же
запис, без повторного сканування.

## Розширення списку показників

Список аналізів, які розпізнаються автоматично, — у `ocr.js`,
масив `TEST_DICTIONARY`. Кожен запис має: `key`, `label`, `pat` (regex для
пошуку назви в тексті), `unit`, `ref` (діапазон). Додати новий показник —
додати ще один об'єкт у цей масив.
